# Руководство пользователя

> Для того, кто делает клипы в веб-интерфейсе. Установкой и обслуживанием
> занимается администратор (см. [ADMIN_GUIDE.md](ADMIN_GUIDE.md)).

Всё управление — в браузере. Названия кнопок в этом документе даны так, как они
написаны в интерфейсе (по-английски).

---

## 1. Как открыть

Откройте в браузере адрес, который дал администратор. При установке на этой же
машине это обычно `http://127.0.0.1:8080`.

- Если пароль не настроен (вариант по умолчанию), интерфейс открывается сразу.
- Если администратор задал общий пароль, появится страница **Password** — введите
  пароль и нажмите **Sign in**.

После входа вы попадаете на главную страницу (Dashboard).

---

## 2. Главная страница (Dashboard)

Сверху — три счётчика: **Total Jobs** (всего задач), **Success Rate** (доля
завершённых) и **Avg Processing Time** (среднее время задачи). Ниже — таблица
**Jobs** со списком задач: ID, исходное видео (Input), статус (Status), дата
создания (Created) и кнопка **View**.

Кнопки справа над таблицей:

- **New Job** — создать задачу.
- **Settings** — настройки по умолчанию для новых задач (см. раздел 10).
- **Diagnostics** — состояние системы и проверка видеокарты (см. раздел 8).
- **Shut down** — выключить систему (см. раздел 9).

Чтобы открыть задачу, нажмите **View** в её строке.

---

## 3. Создание задачи (New Job)

Кнопка **New Job** открывает форму **Create New Job**.

1. **Job Type** — что делаем:
   - **Video Clips** — готовые вертикальные клипы (основной режим);
   - **Draft (Chapters & B-roll)** — черновик: оглавление по таймкодам и (по
     желанию) идеи для вставок, клипы не рендерятся.
2. **Input Source** — путь к файлу на диске или ссылка на YouTube. Либо поле
   **Or Upload File** — выберите файл видео (mp4, mkv, avi, mov, webm).
3. Для **Draft** дополнительно: **Min Minutes** / **Max Minutes** — желаемая
   длительность глав; **Chapter count (optional)** — точное число глав; галочка
   **Generate B-roll suggestions** и **Suggestion count (optional)**.
4. **Profile (optional)** — профиль настроек. Обычно оставляют **Default**.
5. **Config Overrides (optional)** — продвинутая настройка: JSON с изменением
   параметров. Не трогайте, если не знаете, зачем это.
6. Нажмите **Create Job**.

При загрузке файла показывается прогресс в процентах. Размер файла ограничен
настройкой администратора (по умолчанию 10 ГБ); если файл слишком большой или
мало места на диске, интерфейс покажет причину отказа до начала передачи.

После создания вы попадёте на страницу задачи.

---

## 4. Страница задачи

Показывает статус задачи и ход обработки.

**Этапы** (карточка **Pipeline Progress**) идут по очереди:

1. `ingestion` — подготовка видео;
2. `transcription` — распознавание речи;
3. `scoring` — поиск лучших моментов;
4. `face_cropping` — кадрирование 9:16 по лицу;
5. `rendering` — сборка клипов.

Статус каждого этапа: `pending` (ждёт), `running` (идёт), `completed`,
`failed`, `skipped` (пропущен — уже был готов).

**Кнопки вверху:**

- **Cancel job** — отменить выполняющуюся задачу. Готовые этапы сохраняются.
- **Resume** — продолжить упавшую или отменённую задачу с последнего готового
  этапа (появляется для задач со статусом `failed` или `cancelled`).
- **Review Clips** — открыть просмотр клипов (только для завершённой задачи
  типа Video Clips).
- **Delete** — удалить задачу целиком вместе с клипами и файлами (безвозвратно).
- **Back to Dashboard** — вернуться к списку задач.

**Что ещё можно увидеть на странице:**

- **Logs** — журнал задачи; дописывается, пока задача идёт, и остаётся после
  завершения.
- **Error** (красный блок) — текст ошибки упавшей задачи.
- Жёлтый блок уведомлений — если часть результата получена упрощённым способом
  (например, без языковой модели), здесь объяснена причина.
- Плашка о том, что исходное видео удалено для экономии места (клипы при этом
  сохранены, продолжить задачу уже нельзя).

### Если задача упала

1. Откройте страницу задачи — в красном блоке **Error** написан текст ошибки.
2. Посмотрите **Logs**.
3. Нажмите **Resume** — задача продолжится с последнего готового этапа.
4. Если не помогает, откройте **Diagnostics**, нажмите **Copy report** и
   приложите отчёт к вопросу администратору.

## 5. Просмотр и отбор клипов (Review)

На странице завершённой задачи нажмите **Review Clips**. Откроется **Review
Clips**: сверху видеоплеер в вертикальной рамке 9:16, под ним номер клипа
(например, `clip_001`) и его свойства (**Score** — оценка, **Duration** —
длительность, **Tags** — темы).

Для каждого клипа есть три решения (карточка **Review Actions**):

- **Keep (K)** — оставить;
- **Reject (R)** — отклонить;
- **Edit (E)** — нужна правка.

Кнопки **Previous** / **Next** листают клипы. Можно пользоваться клавиатурой:
`K`, `R`, `E` — решения, стрелки `←` / `→` — предыдущий / следующий клип.

Рядом с номером клипа — кнопки **Download MP4** (скачать клип) и
**Subtitles (SRT)** (скачать субтитры, если они есть).

В карточке **Notes** можно записать заметку о клипе — что поправить или почему
он нравится. Заметка сохраняется, когда вы уйдёте из поля (по blur) или по
кнопке **Save note**; рядом появляется надпись **Saved** (или ошибка, если
сохранить не удалось).

Оценки и заметки сохраняются автоматически и не сбрасываются при повторной
обработке.

---

## 6. Черновик: главы и B-roll

Для задачи типа **Draft (Chapters & B-roll)** после завершения на странице
появляются:

- **Chapters** — оглавление по таймкодам, кнопка **Copy YouTube Format**
  копирует текст в формате глав YouTube/VK;
- **B-roll Suggestions** — идеи для вставок с таймкодами, кнопка **Copy as
  Text**.

Это текстовые материалы для монтажа; клипы в этом режиме не создаются.

---

## 7. Сколько занимает обработка

Время зависит от железа. Замер на лекции 25 минут (1080p), Docker-образ
`openvino`, Intel Arc B580 + Xeon E5-2630 v2: вся задача — около 10 минут
(9:38), 12 клипов. На машине без видеокарты скоринг языковой моделью может идти
часами (администратор обычно настраивает API-провайдера).

---

## 8. Диагностика (Diagnostics)

Страница **Diagnostics** (кнопка на Dashboard) показывает:

- версию и бэкенд (GPU), работает ли воркер задач;
- **GPU check** — самопроверка видеокарты; кнопка **Check again** запускает её
  заново (между задачами);
- **Models** — состояние моделей (проверка sha256);
- **ffmpeg and disk** — версия ffmpeg и свободное место.

Кнопка **Copy report** копирует всё это одним текстом — приложите его к вопросу
администратору.

---

## 9. Выключение (Shut down)

Кнопка **Shut down** на Dashboard останавливает систему и освобождает память;
клипы и настройки сохраняются. Если в этот момент идёт задача, можно выбрать:

- **Stop it now and continue from its last stage on the next start** —
  остановить и продолжить при следующем запуске;
- **Wait until it finishes, then shut down** — дождаться конца;
- **Cancel it** — отменить.

После подтверждения откроется страница **/shutdown**, которая покажет ход
выключения до надписи «Shut down». Запускает систему заново администратор
(`just up`). Если 60 минут никто не открывает страницы и нет задач, система
выключается сама.

---

## 10. Настройки (Settings)

Страница **Settings** (кнопка на Dashboard) задаёт значения по умолчанию для
новых задач. Настройки сгруппированы по разделам:

- **Clips** — сколько клипов предлагать на видео (`Clips per video`, 1–30),
  минимальная и максимальная длительность в секундах, минимальная оценка
  `Min score` (0–1).
- **Speech** — язык аудио: `auto` (определить самому), `ru`, `en` или другой
  код Whisper.
- **Subtitles** — стиль субтитров (`typewriter`, `default`, `modern`,
  `minimal`).
- **Analysis (LLM)** — языковая модель, которая выбирает клипы: провайдер
  (`llama_cpp` — локальная модель на вашей видеокарте, `openai` / `anthropic` —
  внешний API); для API-провайдеров — модель, адрес API и ключ. Выключать LLM не
  стоит: без неё клипы выбираются простыми эвристиками и получаются заметно хуже.
- **Storage** — сколько дней хранить исходное видео (`0` — навсегда) и порог
  предупреждения о размере загрузок.
- **Hardware (advanced)** — видеокодировщик и декодер кадров; менять, только
  если что-то не работает на вашей машине.
- **Advanced** — те же настройки в виде JSON, для ключей, которых нет в форме.

У каждого поля — подсказка. Поле, отличающееся от значения по умолчанию,
помечено **changed**, и рядом есть кнопка **Reset** (вернуть значение по
умолчанию); **Reset all** сбрасывает все настройки.

Нажмите **Save Changes**, чтобы применить. Сохраняются только изменённые
значения — в файл `data/settings.yaml`; `config/config.yaml` остаётся как при
установке. Ошибки сервера (например, невалидное значение) показываются прямо в
форме. Если файл настроек повреждён, страница показывает жёлтое предупреждение,
а сохранение заменяет его исправным.

> Настройки влияют на следующие задачи; уже запущенные или готовые задачи они
> не меняют.
